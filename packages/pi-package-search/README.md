# @hk-vk/pi-package-search

Browse, inspect, and install packages from the official Pi catalog.

## Install

```bash
pi install npm:@hk-vk/pi-package-search
```

## Use

```text
/pi-package-search
/pi-package-search github tools
```

The browser searches `https://pi.dev/packages`, shows package metadata and installed status, and confirms installs before running `pi install`.
